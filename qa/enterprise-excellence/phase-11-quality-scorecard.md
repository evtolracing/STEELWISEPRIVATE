# Phase 11: quality scorecard for scale, concurrency, recovery and reconciliation

Scores are a judgement from the evidence named, not a measurement, on the scale of `quality-scorecard.md` (target 95). A subject with no evidence is NOT ASSESSED and gets no number.

Date: 2026-11-18. Everything here was measured in this session on one local machine (4 processors, 15.7 GB), against local PostgreSQL 16 databases whose names contain `qa`, with synthetic data only, three server copies connected as the least-privilege role `steelwise_runtime` behind one front door, and a local stand-in for every outside service. Nothing was run against the live database, the host or any real partner, carrier, payment or accounting system. Anything not run is marked NOT VERIFIED.

Three facts hold every score down however clean the runs are: one machine carried the database, the server copies and the load together; the day is a model built on assumptions, not on the business's real volumes; and every outside service is a stand-in.
